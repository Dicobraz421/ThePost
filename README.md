# The Post

Open-source корпоративный сервер электронной почты и совместной работы — замена Microsoft Exchange на открытых стандартах
(SMTP, IMAP, JMAP, CalDAV, CardDAV). Rust, Linux, один бинарный файл; PostgreSQL + S3; профили SMB и Enterprise.
