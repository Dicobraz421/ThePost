# 2026-10-30 — удаление папок, корзина, надгробия BLOB, RLS

Основание — вопросы волны meta-01 (PR #14).

- Удаление папки с вложенными: решение принимает пользователь в клиенте. `MailboxStore::delete(.., cascade = false)` → `Conflict`;
  клиент (IMAP, JMAP `mailboxHasChild`, веб-интерфейс, Admin API) предупреждает «удалить вместе с вложенными?» и повторяет
  вызов с `cascade = true`. Всё поддерево удаляется одной транзакцией, письма — в корзину; системная папка в поддереве — `Forbidden`.
- BLOB: `finalize_delete` оставляет надгробие с поколением удалённого объекта (срок `MetaConfig::blob_tombstone_ttl`, 24 ч):
  загрузка, начатая до удаления, получает `Bumped`, а не ссылку на удалённый объект.
- Корзина сохраняет `MessageId`: `to_trash`/`restore` меняют папку и UID; `copy`/`move_to` создают новые `MessageId`.
- RLS действует, только если роль приложения не суперпользователь и без BYPASSRLS — проверка в `thepost doctor` (META-07).
- `serde` в зависимости tp-meta (полоса deps) — для `Deserialize` у `MetaConfig`.
