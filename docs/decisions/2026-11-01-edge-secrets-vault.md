# 2026-11-01 — секреты узла edge — напрямую из хранилища

Заменяет пункты 2–3 решения `2026-10-31-secrets-availability-edge.md` (доставка секретов edge через transport, вариант `{ file: }`).

- Основание: edge без очереди (решение 2026-11-01) сам соединяется с transport, путь DMZ → внутренний контур уже есть;
  правило «готовое вместо своего» (2026-10-31).
- Edge читает свои секреты из хранилища как остальные узлы (SRS 2.6, 6.7): отдельная роль входа и политика только на
  чтение пути edge; вход по сертификату узла или AppRole (secret_id — учётные данные systemd); короткий срок токенов;
  доступ к API хранилища из DMZ — только с адресов edge; журнал аудита хранилища включён.
- Вариант `{ file: }` в `SecretRef` не нужен: карточка CTR-17 и волна contracts-07 отменены.
- Для модуля «Развёртывание» (визуальный установщик ролей, SRS 1.3) и эталонных Ansible/Helm (SRS 5.6): по топологии
  формировать матрицу сетевого доступа между ролями и правила межсетевого экрана (DMZ: edge → transport SMTP,
  edge → хранилище секретов), роли входа и политики хранилища по пресетам, учётные записи PostgreSQL по ролям.
