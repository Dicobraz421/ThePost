# 2026-10-29 — базовые решения владельца

Основание — экспертиза SRS ред. 2 (`docs/spec/APP-A.md`, `APP-B.md`).

- Продукт — почтовый сервер, не «всё в одном»: антиспам/антивирус, мониторинг, СРК, балансировка, HA СУБД — внешние системы.
- Модульный монолит: один бинарник, роли по config.yaml. Kubernetes — опция для динамической нагрузки; основной Enterprise-вариант — ВМ под systemd.
- Без собственного прокси: TLS и проверка подлинности почты — в ядре; L4-балансировщик заказчика (рекомендации SRS 6.1).
- PostgreSQL 16+ — метаданные; HA — у заказчика (Patroni / CloudNativePG / управляемая); PgBouncer в Enterprise; схема готова к шардированию.
- BLOB — локальный диск (SMB) / S3, эталон SeaweedFS; дедупликация MIME-частей в tenant; протокол поколений; инвариант W.
- Поиск — Tantivy во всех профилях, индекс на ящик, сегменты в BlobStore.
- Шина событий — в процессе (SMB) / Valkey (Enterprise).
- Бэкап: продукт даёт корзину, экспорт/импорт API и verify; копии делают внешние СРК.
- Outlook — не целевой клиент. SAML — вместе с веб-клиентом.
- Код Stalwart не форкаем; используем его пермиссивные крейты (mail-parser, mail-auth, mail-builder, mail-send, smtp-proto, calcard).
- В дорожную карту (вне текущего объёма): веб-клиент, утилиты миграции, собственный генератор нагрузки.
- Лицензии: в бинарник — только пермиссивные (cargo-deny); внешние системы — любые OSI.
