# 2026-10-30 — базовая поставка, модули, роли

Основание — сравнение со Stalwart и уточнение SRS (ред. 4).

- Базовая поставка — минимум для замены Exchange; календари и контакты — в базе. Остальное — дополнительные модули (SRS 1.3).
- Весь код, включая модули, открыт (MIT / Apache-2.0); лицензию пересматриваем только при коммерциализации. Лицензионных ключей нет.
- Модули — cargo features + `modules.<имя>.enabled`; только через точки расширения ядра (SRS 2.5): трейты, реестр ролей/capability/маршрутов, события outbox, точки принятия решений, схема `mod_<имя>`.
- Мультитенантность: в базе — tenant в ключах, запросах, RLS, Admin API, политиках (SRS 3.8); реализация — модуль.
- GUI развертывания — модуль поверх эталонных Ansible/Helm; в базе — JSON Schema конфигурации, `doctor --json`.
- Роли: новая роль `submission` (587/465); пресеты all/edge/transport/access/backend/mailbox; слой данных (PostgreSQL, BLOB, Valkey) — внешний.
- Режим edge для DMZ: без доступа к БД, локальная очередь, реплика получателей из внутреннего контура (SRS 2.6).
- Извлечение текста вложений — пул отдельных подпроцессов; ленивая инициализация ролей, RSS простаивающей роли ≤ 64 MB (SRS 2.7).
- Трудоёмкость не пересчитывается.
