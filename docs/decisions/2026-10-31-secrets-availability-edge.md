# 2026-10-31 — недоступность хранилища секретов, секреты узла edge

Основание — уточнение SRS 6.7 (PR #94).

- Запуск узла без доступа к хранилищу невозможен. Работающий узел при недоступности хранилища продолжает работу
  с секретами в памяти до истечения аренд, повторяет подключение, сообщает в метриках и журнале (SRS 6.7).
- Узел edge (DMZ) доступа к хранилищу секретов не имеет (SRS 2.6). Вариант «б»: секреты edge (ключ TLS приёма,
  сертификат и ключ канала к transport) доставляют узлы transport по каналу синхронизации получателей, открываемому
  изнутри, с обновлением при ротации. Начальный сертификат канала — файлом при развёртывании (systemd credentials /
  секрет Kubernetes). На edge — в памяти и в файле с доступом только для процесса.
- Доработка контракта: `SecretRef` — вариант `{ file: "<путь>" }`, допустимый только на узлах edge; значение в открытом
  виде по-прежнему ошибка (карточка CTR, PR класса B).
