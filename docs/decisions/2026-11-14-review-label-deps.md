# 2026-11-14. Стоп владельца — меткой; крупные обновления зависимостей — тест и мерж

Владелец (бот `dicobraz-bot` заблокирован GitHub, автоапрув не работает; PR агентов — от аккаунта владельца):

1. Обязательный approve владельца не требуется. Ручной стоп — метка `owner-review`: `gate` падает, пока метка стоит;
   сняли метку — `gate` перезапускается (`ci.yml`, события `labeled`/`unlabeled`). Без метки PR сливается по зелёному CI.
2. Обновление зависимости с крупной версией (PR dependabot) — не откладывать: агент проверяет его локально теми же
   шагами, что CI (для консоли — `npm ci`, typecheck, lint, vitest, audit, лицензии, build), и при успехе ставит
   на мерж; при провале — закрывает PR с причиной и, если причина постоянная, добавляет `ignore` в `dependabot.yml`
   с условием снятия. Первый случай — #452 (react-router 8 несовместим с `@refinedev/react-router` 2.x, peer `^7`).
3. PR, issue и запуски CI в отчётах владельцу — всегда ссылкой.
