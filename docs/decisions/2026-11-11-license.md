# 2026-11-11 — лицензия проприетарная

Решение владельца.

- Код The Post, включая модули, — проприетарный: «все права защищены», файл `LICENSE` в корне. Использовать,
  копировать, менять и распространять код без письменного разрешения правообладателя нельзя; коммерческие
  лицензии — отдельным договором. Лицензионных ключей в продукте по-прежнему нет.
- В `Cargo.toml` — `license = "LicenseRef-Proprietary"`; в `deny.toml` она разрешена для своих крейтов.
  Политика лицензий библиотек (SRS 7.1: только пермиссивные) не меняется.
- Версии, опубликованные до 2026-11-11 под MIT / Apache-2.0, остаются под прежней лицензией.

Заменяет пункт «Весь код, включая модули, открыт (MIT / Apache-2.0)» решения 2026-10-30 «базовая поставка,
модули, роли» и строки об открытой лицензии продукта в `docs/spec/S1.md`, `docs/spec/S7.md`.
