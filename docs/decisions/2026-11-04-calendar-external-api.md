# 2026-11-04. Внешние встречи: API занятости и публикации для клиентов

Решение владельца (обсуждение 2026-11-04, проверка клиента Postman). Дополняет 2026-11-04-exchange-parity.

- Стандартного JMAP-метода занятости по адресу нет (`Principal/getAvailability` — только пользователи сервера), поэтому:
  JMAP-расширение `urn:thepost:availability`, метод `Availability/get` (адреса, интервал → занятость, источник, уровень
  детализации). Источник выбирает сервер: пользователи организации; ссылки занятости (FBURL) из GAL и контактов и шаблон
  домена-партнёра из политики; модуль «Федерация календарей» — через точку расширения источников занятости.
- Сервер запрашивает внешние ссылки только по HTTPS, с таймаутом и кэшем; внутренние и частные адреса запрещены (защита от SSRF).
- JMAP-расширение `urn:thepost:calendarpublish`: создать, перечислить, отозвать ссылку публикации календаря с уровнем детализации.
- Клиент определяет расширения по `capabilities` сессии; без них (другие серверы) — свои запасные пути.
- Postman: занятость внешних участников (расширение, запасной путь — FBURL из карточки контакта), управление публикацией,
  подписка на опубликованные календари ICS (карточки в репозитории Postman).
