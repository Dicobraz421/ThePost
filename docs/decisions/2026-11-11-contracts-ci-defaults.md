# 2026-11-11: имена шардов, токен первого администратора, цепочка поставки

Ответ владельца в сессии оркестратора — «по рекомендации» (волны contracts-22, contracts-29, ci-03; PR #280, #282, #281).

1. **Пара (шард, раздел) — тип `ShardPartition`** (CTR-34). `Partition` остаётся номером раздела: его используют tp-meta,
   tp-cluster и thepost. Выравнивание имён с SRS — при переходе этих полос на шарды, отдельной волной не делается.
2. **Локальный токен первого администратора — строго одноразовый** (CTR-41): гасится первой успешной проверкой.
   ADM-11 обменивает его на сессию Admin API (или на настройку провайдера OIDC); многоразового окна нет.
3. **Известные уязвимости в `Cargo.lock` — явный список пропусков `cargo audit`** (calamine < 0.38, libsqlite3-sys < 0.39,
   zip < 9 через mail-auth). Обновление calamine и libsqlite3-sys — карточка DEPS-01; zip — после выпуска mail-auth на zip 9.
   Новые уязвимости красят `deny`.
4. **Воспроизводимость сборки бету пока не блокирует** (красный job `repro`). Блокировку включить, когда job стабильно зелёный.
5. **Пакет образа в ghcr.io — публичный.** После первой ночной сборки проверить видимость пакета и при необходимости открыть.
