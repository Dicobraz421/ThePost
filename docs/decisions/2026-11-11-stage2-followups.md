# 2026-11-11: решения по отчётам волн этапа 2

Ответы владельца в сессии оркестратора (отчёты ci-04, platform-11, jmap-14, deps-01, app-07, app-04).

1. **`doctor`: сторонние расширения PostgreSQL** — WARN, не FAIL: продукт в них не нуждается, но они допустимы.
2. **Переход на mail-auth ≥ 0.14 и mail-send 0.7** — DEPS-02: снимает четыре пропуска `cargo audit` по zip 8.
3. **Подпись профиля `.mobileconfig`** — TLS-сертификатом сервера (ключ секции `tls`): зависимость `cms` — DEPS-03,
   подпись — JMAP-22. Без подписи iOS и macOS показывают «Не проверен».
4. **Постраничный список учётных записей в Admin API** — ADM-12 (сейчас — только поиск по имени входа).
5. **`auth.abuse.fail_closed` в сборке узла** — APP-20: ошибка `AbuseGuard::check` запрещает вход, если ключ включён.
6. **Исключения проверки интерпретаторов** (CI-05): сценарий motd и модули gdb в distroless остаются исключениями с
   причиной; compose и стенд нагрузки — средства разработки; Ansible — инструмент установки. `bootstrap.sh` Helm-чарта
   OpenBao — заменить (этап 3, полоса deploy).
7. **Landlock на ядрах до 6.10** — WARN (защита неполная).
8. **libsqlite3-sys < 0.39 — пропуск в `cargo audit` остаётся**, пока sqlx-sqlite не выйдет на новую версию: в сборку
   крейт не попадает (`cargo tree -i libsqlite3-sys --target all` пуст), это только запись в `Cargo.lock`
   (слабая зависимость sqlx). Брать sqlx из git запрещает `deny.toml`.

## Отчёт smtp-06 (SMTP-20…23)

9. **Модерация письма правилом потока** — одна очередь модерации для групп и правил: в контракте `HeldMessage.group`
   необязательна, у записи — список модераторов (CTR-43 → META-44 → SMTP-30). До них — временный отказ 451.
10. **Домен другой организации на узле** — 451 до модуля «Мультитенантность» (для SMB организация одна).
11. **Доверенные источники по сертификату (mTLS)** — слушатели smtp запрашивают необязательный сертификат клиента
    с CA из конфигурации (PLT-22); до этого источник распознаётся по адресу.
12. **SRS — свой код** (≈200 строк, HMAC-SHA256, эталон RFC 4231): в mail-auth SRS нет, поддерживаемых крейтов нет.
