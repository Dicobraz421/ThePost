# 2026-10-31 — конверт письма в ingest и пересылка копий

Основание — issue #84 (волна mailstore-01, PR #85). Решение владельца — вариант А.

- `IngestRequest` получает адрес отправителя с конверта (`mail_from`, из SMTP `MAIL FROM`; пустой — уведомление о
  недоставке). Хранилище не угадывает отправителя по заголовку `Return-Path`.
- Результат `ingest` возвращает список внешних адресов для пересылки (`forward`), которые запросили точки принятия
  решений модулей (`CopyTo::Address`). В очередь исходящей почты их ставит вызывающий (smtp, позже jmap) — хранилище
  писем не отправляет почту.
- Копии в папки (`CopyTo::Mailbox`) по-прежнему делает хранилище.
