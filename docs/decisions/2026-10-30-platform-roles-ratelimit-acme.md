# 2026-10-30 — платформа: сбой роли, блокировки, имена ACME

Основание — вопросы волны platform-02 (issues #49–#51).

- #49 Упавшая роль (ошибка или паника) перезапускается внутри процесса, остальные роли работают дальше. Пока роль
  не поднялась, она не готова, и `/healthz/ready` отдаёт 503 (готовность узла — по всем его ролям). Пауза перед перезапуском удваивается: 1 с, 2 с, 4 с … до 60 с.
  Больше `runtime.restart.max_restarts` (5) падений одной роли за `window_secs` (600 с) — узел останавливается штатно
  (drain), процесс перезапускает systemd или Kubernetes. `max_restarts: 0` — прежнее поведение: первое падение
  останавливает узел. Метрика `tp_role_restarts_total{role}`.
- #50 Учётная запись при превышении лимита попыток только ограничивается (`retry_after`), не блокируется: иначе
  посторонний может запереть владельца. Блокируются источники — IP и подсети /24, /64.
- #51 `acme.domains` обязателен при `acme.enabled: true`; имя по умолчанию не подставляется.
