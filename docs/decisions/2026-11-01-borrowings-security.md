# 2026-11-01 — заимствования из Postfix, Dovecot, Exchange; поведение под нагрузкой; базовые принципы безопасности

Основание — сравнение с qmail, Postfix, Dovecot, Exchange (обсуждение владельца, 2026-11-01).

- Узел edge — без локальной очереди: сквозная передача на transport, 250 — после сохранения во внутреннем контуре,
  при недоступности — 4xx (SRS 2.6). Файловых очередей в продукте нет.
- Заимствования в базовую поставку: экран соединений (postscreen), планировщик исходящей очереди по доменам (qmgr),
  ступенчатое поведение под нагрузкой (back pressure), адресация (псевдонимы, catch-all, подадреса), группы рассылки
  с модерацией, журнал доставки (message tracking), политики по доменам назначения (коннекторы), проверка квоты до 250
  и предупреждения, сжатие BLOB zstd, обучение антиспама по перемещению в «Спам», норматив памяти на соединение
  (SRS 2.6, 2.7, 3.2, 4.1, 4.5, 4.7, 5.2, 6.3, Д.7). Правила потока почты (transport rules) — модуль (SRS 1.3).
- Поведение под нагрузкой: сначала масштабирование ресурсов, затем ограничение потока; пороги — относительно текущих
  лимитов cgroups, пересчитываются при изменении (SRS 2.7, 6.3).
- Минимальные привилегии — базовое требование: без root, seccomp и Landlock по ролям, hardening systemd и Kubernetes,
  раздельные учётные записи PostgreSQL (SRS 2.7, 3.1). Базовые принципы безопасности — SRS 6.8.
- Не заимствуем: director/proxy и dsync Dovecot, LMTP, DAG Exchange, файловые очереди Postfix/qmail.
