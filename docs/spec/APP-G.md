# Приложение Г. Оценка трудоёмкости

Оценка охватывает серверную часть в границах п. 1.1. Не включены веб-клиент, утилиты миграции и генератор нагрузки (приложение Е). Учтено использование библиотек mail-parser, mail-auth, mail-builder, mail-send, smtp-proto, calcard — экономия 15–20 % относительно собственной реализации.
