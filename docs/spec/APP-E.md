# Приложение Е. Дорожная карта (вне текущей редакции)

**Таблица: Дорожная карта**

| Направление | Содержание |
|---|---|
| Веб-клиент | SPA поверх JMAP: почта, календари, контакты, задачи; веб-консоль администратора; вход по SAML 2.0 |
| Утилиты миграции | Импорт из Microsoft Exchange (EWS), PST, IMAP-источников через Admin API импорта (п. 5.2) |
| Генератор нагрузки | Собственный генератор корпуса и сценариев с реалистичным распределением размеров, вложений и дублей |
| Мобильное JMAP-приложение | Нативное приложение или PWA с push-уведомлениями |
| eDiscovery | Интерфейс поиска по множеству ящиков с выгрузкой результатов |
| Сертификация | Оценка требований ФСТЭК России, поддержка ГОСТ-TLS |
