# Приложение И. Соответствие функциям Exchange

Перечень функций Microsoft Exchange Server 2019 (Subscription Edition), сгруппированный по разделам документации, со способом покрытия в продукте. Функции только Exchange Online и единая система обмена сообщениями (удалена в Exchange 2019) не включены. Перечень сверяется при каждом изменении функционального состава продукта (решение 2026-11-04).

Способ покрытия: база — функция базовой поставки; модуль — дополнительный модуль (п. 1.3); иным механизмом — задача решается другим средством продукта или внешней системой по стандартному интерфейсу; вне назначения — сознательно не поддерживается.

**Таблица: Итог соответствия**

| Способ покрытия | Число функций |
|---|---|
| База | 59 |
| Модуль | 13 |
| Иным механизмом | 21 |
| Вне назначения | 11 |
| Всего | 104 |

Сверх функций Exchange продукт реализует: JMAP, CalDAV и CardDAV, DKIM, DMARC, ARC, MTA-STS, TLS-RPT, дедупликацию тел писем, хранение в S3, шардирование, геораспределение, хранилище секретов, ГОСТ-TLS (модуль), Sieve и ManageSieve.
