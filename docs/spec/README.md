# Спецификация The Post (SRS, ред. 5)

Правило редакций: каждое существенное изменение спецификации увеличивает номер редакции на единицу; приложения в документе следуют после основного текста.

Ред. 5 (2026-11-04) — взаимодействие компонентов через PostgreSQL без Valkey и требования к СУБД по стандарту; состав функций транспорта и внешний MTA на периметре (приложение Ж); масштабирование, шарды, чтение с реплик, геораспределение, CLI и веб-консоль администратора, схемы развёртывания (приложение З) (решения `docs/decisions/2026-11-01-interaction-db-ha.md`, `2026-11-01-transport-scope-external-mta.md`, `2026-11-01-scale-shards-geo-admin.md`).
Ред. 4 (2026-10-30) — базовая поставка и дополнительные модули, точки расширения, заготовка мультитенантности, пресеты ролей, режим edge, хранилище секретов, заимствования из Postfix, Dovecot и Exchange, базовые принципы безопасности (решения `docs/decisions/2026-11-01-borrowings-security.md`, `docs/decisions/2026-10-30-base-and-modules.md`, `2026-10-30-config-events-secrets.md`). Ред. 3 — `v2 Спецификация технических требований.docx` (2026-10-29); с ред. 4 источник истины — этот каталог. Изменения — только PR класса B.
