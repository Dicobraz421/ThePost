# SMTP-48: iTIP — письмо с несколькими заголовками `From` не применяется

Аудит приёма iMIP: `itip::extract` сверяет с участниками адрес из одного заголовка `From` (`mail_parser` берёт один
из нескольких), а DMARC (mail-auth) проверяет адреса всех заголовков `From`. При нескольких заголовках применённый
`From` может разойтись с тем, что проверил DMARC. RFC 5322 §3.6 допускает ровно один `From`.

## Сделать
- `itip::extract`: заголовков `From` больше одного — `Err("у письма не один заголовок From")`, письмо доставляется
  без применения iTIP.
- Тест: второй заголовок `From` с тем же и с чужим адресом.

## Приёмка
- Письмо iMIP с двумя заголовками `From` — `Some(Err(…))`; с одним — как раньше.
