## Сделать
- Раздел меню «Доверие»: переключатель уровня — установка (администратору установки), организация, группа (выбор
  группы). Матрица — таблица antd: строки — функции, столбцы — свои, партнёр, сосед по установке, интернет; в клетке —
  `Select` из значений не выше потолка, значения выше потолка видны, но недоступны, с подсказкой «потолок уровня
  … : …». Закреплённые клетки — текстом с замком и пояснением.
- У клетки — источник действующего значения (установка, организация, группа) и метка «выше потолка» для
  `over_ceiling`. Ошибки 422 — у клетки с текстом `detail` сервера.
- Вкладка «Партнёры» (уровень организации): список доменов, добавление и удаление; домены автопересылки — там же.
  «Сбросить уровень» — с подтверждением.
- Карточка учётной записи — вкладка «Доверие»: действующая матрица с источником по клетке.
- Форма автоответа — поля внешних темы и текста с пояснением «пока пусто — внешним ответа нет».
- Подписи функций и значений — как в разделе «Кто с кем и что может» ADMIN-GUIDE.

## Как делают другие
- Google Admin — настройки календаря по OU и группам с наследованием и указанием, откуда значение
  (https://knowledge.workspace.google.com/admin/calendar/set-google-calendar-sharing-options).
- Exchange admin center — отдельные страницы Sharing Policy и Organization Relationship
  (https://learn.microsoft.com/en-us/exchange/sharing/sharing-policies/sharing-policies).
- Отличие: вся матрица на одном экране, потолок виден у клетки, а не узнаётся из ошибки.

## Приёмка
- Тесты: значения выше потолка недоступны; закреплённые клетки не редактируются; ответ 422 показывается у клетки;
  переключение уровня перечитывает матрицу; карточка учётной записи показывает источник клетки.
- Ручная проверка на стенде: установка снижает потолок — у организации клетка «выше потолка»; партнёр добавлен и
  удалён; изменения видны в журнале аудита.
