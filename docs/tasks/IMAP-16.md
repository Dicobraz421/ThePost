Отчёт imap-03: POP3 не блокирует ящик на время сессии (RFC 1939 §8 требует); общие папки — только чтение.

## Сделать
- POP3: исключительная блокировка ящика на сессию (в пределах узла; между узлами — лиза, если есть в контрактах,
  иначе — описать в отчёте); вторая сессия — `-ERR [IN-USE]` (RFC 2449).
- Общие папки по правам ACL (RFC 4314): `w`/`s` — STORE флагов, `t`/`e` — EXPUNGE, `i` — APPEND и COPY/MOVE в папку.
- Тесты на фейках: две сессии POP3; STORE/EXPUNGE/APPEND в чужой папке с правами и без.
