Веб-консоль — одностраничное приложение на Refine (SRS 5.2), исходники в `console/`, статика вшита в бинарный файл.

## Сделать
- `lanes.toml`: `[lane.console] paths = ["console/*"]`.
- Job `console` (только при изменениях `console/**`): Node LTS, `npm ci` по lock-файлу, проверка типов, линтер, `vitest`, `npm run build`;
  кэш npm; `npm audit --omit=dev` и проверка лицензий зависимостей по списку `deny.toml`; укладывается в CI ≤ 7 мин.
- Бета и выпуск: сборка `console/dist` до `cargo build` и фича `console` у tp-admin (DEPS-05); `console/dist` — в `.gitignore`.

## Приёмка
- PR с правкой `console/` запускает job и зелёный; PR без неё — job пропущен; бета содержит консоль.
