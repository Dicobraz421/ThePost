Синк 12.11, часть 2, решение 68: консоль из архива `console/dist` на отдельном веб-сервере.

## Сделать
- Файл `config.json` рядом с `index.html` (необязательный): `{"apiBase": "https://узел[:порт]"}`; нет файла или поля —
  тот же источник, что у страницы (как сейчас при раздаче узлом). Читается один раз при старте, до входа.
- Все запросы провайдера данных и `authProvider` — относительно `apiBase`; OIDC — без изменений.
- `console/README.md`: раздача архива веб-сервером (пример nginx), `config.json`, настройка `admin.console.cors_origins`
  на узле и `connect_src` для адреса API.

## Приёмка
- Тест на заглушке API: с `config.json` запросы идут на `apiBase`, без него — на свой источник.
- Ручная проверка на стенде: архив беты на nginx отдельного узла, вход и список учётных записей.
