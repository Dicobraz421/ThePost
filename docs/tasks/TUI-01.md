## Сделать
- `ratatui` + `crossterm`: левая панель — дерево ресурсов (организации → домены, учётные записи, группы, контакты,
  оргструктура, ресурсы, политики, журналы, очередь, конфигурация узла), правая — список/карточка; Tab — смена
  панели; меню (F9); подсказка клавиш: F1 справка, F3 просмотр, F4 правка, F7 создать, F8 удалить, F10 выход.
- Вход через `tp-admin-client` (пароль, OIDC device flow, токен), адрес и CA — как у CLI.
- Нижняя строка — эквивалентная команда `thepost admin …` для выбранного действия.
- 80×24, без мыши (мышь — по желанию), монохромный режим (`NO_COLOR`), русские строки.

## Приёмка
- Тесты отрисовки на `TestBackend`: 80×24, обе панели, подсказка клавиш, строка команды CLI.
- Ручная проверка: по SSH на стенде вход и навигация по дереву.
