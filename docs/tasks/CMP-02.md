Находка CMP-01, п. 2: `/var/lib/thepost/search` не создан — индексатор пишет `Permission denied (os error 13)` каждую
секунду; с созданным каталогом работает. Landlock (`path_beneath_rules`) молча пропускает несуществующие пути, поэтому
каталог, созданный позже, оказывается вне разрешённых.

## Сделать
- В `startup` до `Confinement::apply`: создать недостающие каталоги ролей, разрешённые на запись (`RolePaths`: state, cache,
  blob — в том числе `search.index.dir`), права 0700 учётной записи службы. Файлы (TLS, секреты) не создавать.
- Не удалось создать — запуск прервать с понятной ошибкой (путь, причина), а не тихо работать без каталога.
- Тест: несуществующий каталог индекса в config → после подготовки существует и попадает в правила.
