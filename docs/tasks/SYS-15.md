Ошибка со стенда: `tp_sys::resources` каждые 5 с пишет «лимиты ресурсов узла изменились» при прежних лимитах —
в сравнение `NodeResources` входит `memory_available`, она меняется с каждым чтением (≈17 тыс. строк в сутки).

## Сделать
- Признак «лимиты изменились» — только CPU (квота `cpu.max`, маска привязки) и предел памяти (`memory.max`,
  `MemTotal`): `NodeResources::same_limits`. Доступная память в нём не участвует, в снимке остаётся для потребителей.
- Тестовый журнал `tracing` — общий модуль крейта вместо копии в тестах sandbox.

## Приёмка
- Тест на подменном каталоге cgroups: смена `memory.current` при прежних лимитах — записи нет, смена `memory.max` —
  ровно одна запись.
