# AUTH-19: защита от перебора: адрес `::ffff:a.b.c.d` — как IPv4

Приёмка беты 0.2.0, CMP-01, ошибка 2. Слушатель на `[::]` отдаёт адрес клиента IPv4 в форме `::ffff:a.b.c.d`;
`AbuseGuard::failure` выбирал префикс подсети по `ip.is_ipv4()` и брал `net_prefix_v6: 64`. Все клиенты IPv4
попадали в одну «подсеть» `::/64`: 100 неудач с любых адресов IPv4 блокировали вход всем клиентам IPv4 на 15 минут.

## Сделать
- Адрес попытки приводить к канонической форме (`IpAddr::to_canonical()`) на входе в `AbuseGuard`: один путь для
  счётчиков (`failure`) и проверки блокировок (`check`).

## Приёмка
- `::ffff:10.0.1.5` и `10.0.1.5` — один адрес: общий счётчик и блокировка.
- Адреса IPv4 из разных `/24` не складываются в одну подсеть.
- 100 неудач из `10.0.1.0/24` блокируют только эту `/24`.
