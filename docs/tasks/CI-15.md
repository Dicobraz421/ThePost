## Сделать
- В бете 43320711328 (main 54550abd, 0.2.0) `repro` на обеих целях дал другой sha256 бинаря `thepost`, чем `build`.
  Путь сборки один (`.github/actions/release-build`, cross, `--features console`, пустые RUSTFLAGS), console/dist
  в обоих job совпадает по хэшам файлов. Расхождение — от `rust-embed`: в бинарь вшиваются `last_modified` и
  `created` файлов console/dist, а это время `npm run build` в конкретном job. До CI-08 консоль не вшивалась —
  прошлая бета 43178583865 была воспроизводима.
- Включить у `rust-embed` фичу `deterministic-timestamps` (метки времени — 0). Консоль метками не пользуется
  (`tp-admin/src/console.rs` берёт только `data`).

## Приёмка
- Ручная бета с main после мержа (`gh workflow run beta.yml`): `repro (x86_64-…)` и `repro (aarch64-…)` зелёные,
  sha256 в сводке совпадают с `build`.
