Своя реализация (SRS 4.3). Эталон поведения в тестах — RFC и примеры из них; код Stalwart (AGPL) не заимствуется.

## Сделать
- Лексер RFC 5228 §2: идентификаторы, теги `:x`, числа с `K`/`M`/`G`, строки в кавычках с экранированием, многострочные `text:`
  (до строки из одной точки, удвоение точки), списки строк, комментарии `#` и `/* */`; позиция (строка, столбец) у каждого токена.
- Разбор в AST: команды, блоки `{}`, тесты (в том числе `allof`/`anyof`/`not` с вложенностью), аргументы.
- Лимиты из секции `sieve` (`max_script_size`, `max_nesting`, `max_list_len`) — ошибка разбора, а не паника.

## Приёмка
- Тесты на примерах RFC 5228, 5229, 5230, 5232, 5233 и на ошибках с позицией; proptest: разбор произвольных байт не паникует.
