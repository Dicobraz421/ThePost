## Сделать
- Раздел «Доверие» — ручная раскладка TUI-03 (движок форм по схеме матрицу не покажет): таблица функций × четыре типа
  абонентов, курсор по клеткам стрелками; F4 — выбор значения из допустимых до потолка; закреплённые клетки — знак
  замка и пояснение в строке состояния; «выше потолка» — знак ▲ и цвет роли «внимание».
- F5 — уровень (установка, организация, группа); F8 — сброс уровня с подтверждением; вкладка «Партнёры» — список
  доменов и домены автопересылки (F7 — добавить, F8 — удалить); строка «учётная запись» — действующая матрица с
  источником клетки.
- Ошибка 422 — текст `detail` сервера у клетки. Внизу экрана — эквивалентная команда `thepost admin trust …` для
  каждого действия (решение 118).
- Вмещается в 80×24: подписи функций сокращаются по ширине, полное название — в строке состояния.

## Как делают другие
- Текстовые консоли серверов настраиваются командами (Zimbra `zmprov`, https://zimbra.github.io/adminguide/latest/index.html);
  экран матрицы — наш, чтобы по SSH было видно то же, что в веб-консоли.

## Приёмка
- Тесты на `TestBackend`: значения выше потолка не предлагаются; закреплённую клетку F4 не меняет; «выше потолка»
  видно знаком без цвета (монохром); строка CLI соответствует действию; 80×24 без обрезки клеток.
- Ручная проверка на стенде: изменение клетки и партнёра из текстового интерфейса видно в веб-консоли и журнале аудита.
