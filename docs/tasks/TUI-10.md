## Сделать
- Раздел «Признаки риска» — ручная раскладка TUI-03: вкладки «Каталог», «Пороги», «Пакеты», «Источники»,
  «Срабатывания». Каталог — таблица с курсором; F4 — изменить вес, действие, режим (организации — только строже);
  «только отчёт» и «осиротевшее» — знаками с пояснением в строке состояния.
- Пакеты: список версий; импорт файла с узла (путь — полем ввода, для закрытого контура по SSH), отчёт проверки,
  активация и откат с подтверждением. Источники: свежесть (устарел — знак ▲ и цвет роли «внимание»), импорт,
  «обновить сейчас», учёт по организациям.
- Ошибка 422 — текст `detail` у поля. Внизу экрана — эквивалентная команда `thepost admin risk …` (решение 118).
- Вмещается в 80×24.

## Как делают другие
- Консольная работа с правилами — `rspamadm`, `sa-update --install`
  (https://spamassassin.apache.org/full/4.0.x/doc/sa-update.html); экран — наш, чтобы в закрытом контуре по SSH было
  видно то же, что в веб-консоли.

## Приёмка
- Тесты на `TestBackend`: вес организации ниже установки не принимается; отчёт пакета показан до активации;
  устаревший источник виден знаком без цвета (монохром); строка CLI соответствует действию; 80×24 без обрезки.
- Ручная проверка на стенде: импорт пакета из файла по SSH и откат видны в веб-консоли и журнале аудита.
