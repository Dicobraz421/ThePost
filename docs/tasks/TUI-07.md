## Сделать
- `crossterm` `EnableMouseCapture`: щелчок выбирает строку и панель, двойной — открывает, щелчок по F-клавише внизу —
  её действие, колесо — прокрутка, перетаскивание границы двух панелей меняет их ширину. Клавиатура остаётся полной.
- Плавный курсор — лучший доступный уровень, определяется при старте (ключ `--mouse-cursor` перекрывает):
  1. kitty graphics: картинка стрелки по пиксельным координатам (режим `1016`, SGR-Pixels) со сдвигом внутри ячейки;
  2. sixel — та же картинка;
  3. знакогенератор, как в Norton Commander 5: четыре редких символа перерисовываются под стрелку со сдвигом и ставятся
     блоком 2×2 поверх исходных символов — на консоли Linux через `KDFONTOP` (шрифт возвращается при выходе),
     координаты из `/dev/input` (группа `input`; нет доступа — уровень 4); в терминалах с `DECDLD` (Windows Terminal,
     mlterm, contour) — загрузкой символов, если терминал даёт пиксельные координаты;
  4. подсветка ячейки под мышью (инверсия).
- Протоколы картинок — `ratatui-image`; своей реализации kitty и sixel нет.

## Приёмка
- Тесты: события мыши → действия (выбор строки, F-клавиша, прокрутка, перетаскивание границы); выбор уровня по ответам
  терминала и окружению (таблица случаев); глифы стрелки 2×2 строятся для каждого сдвига внутри ячейки.
- Ручная проверка: kitty или WezTerm (уровень 1), Windows Terminal (уровень 3 через `DECDLD`), консоль Linux на стенде
  (уровень 3 через `KDFONTOP`), xterm без пиксельного режима (уровень 4).
