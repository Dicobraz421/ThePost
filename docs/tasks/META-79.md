## Сделать
- `next_gc_due` по умолчанию берёт срок из `gc_candidates(_, 1)`: если самый ранний обнулённый объект занят ссылкой на
  другом шарде, срок — `None`, и GC не начинает проход, мусор копится (отчёт app-52, #651).
- Шардированный `next_gc_due` в `PgMeta::with_shards`: минимум по всем шардам среди объектов без ссылок.

## Приёмка
- Тест на двух базах: самый ранний обнулённый объект занят на втором шарде, следующий — свободен; срок не `None`,
  проход удаляет свободный.
