# SMTP-28: `Delivery::submit` без очереди — ошибка только для внешних получателей

Отчёты smtp-08 и app-10: без подключённой очереди `Delivery::submit` возвращает `Err` на всю отправку, если среди
получателей есть внешний, — локальные тоже не доставляются.

## Сделать
- Без очереди: локальные доставляются, внешние — `RcptStatus::Failed` (временная ошибка 4.3.0, «очередь недоступна»).
- Пересылки модулей (`Ingested::forward`, `CopyTo::Address`) на локальные адреса — сразу локально, как CMP-04.
- Тесты: смешанный список без очереди; пересылка на локальный адрес без очереди.
