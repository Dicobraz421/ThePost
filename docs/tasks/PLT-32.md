## Сделать
- `ratelimit.trusted: [CIDR, …]` — с адресов этих подсетей ограничение частоты соединений (`RateLimiter`) не действует;
  со всех остальных — как прежде. Защита от перебора паролей (`AbuseGuard`) действует для всех, в том числе доверенных.
- Пустой список — по умолчанию; изменение применяется при перечитывании настроек без перезапуска.
- Зачем (решение владельца 12.11): сканеры, МФУ, системы мониторинга с одного адреса; стенд Д.6 — генератор нагрузки
  доверенный, а ограничение частоты проверяется со второго адреса (DEP-25, отчёт deploy-21 #552).

## Приёмка
- Тест: с доверенного адреса 100 соединений подряд проходят; с недоверенного — срабатывает предел; перебор паролей с
  доверенного адреса блокируется.
