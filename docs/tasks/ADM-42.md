Ошибка 2 приёмки Ф2 (CMP-10, сценарий календарей на стенде): без LDAP нельзя задать псевдоним и признак «скрыта из
книги «Организация»» — на стенде их задавали через SQL. Поля `accounts.aliases` и `accounts.hidden_from_gal` в базе есть
(CTR-53, CTR-83, #715), но заполняла их только синхронизация LDAP; в `AccountPatch`, CLI и консоли этих полей не было.
По SRS 4.1 и 4.5 источник этих данных — каталог и Admin API. Межполосная волна `admin-28` (tp-admin, thepost, console).

## Сделать
- Admin API: `aliases` и `hidden_from_gal` — в ответе учётной записи (`AccountInfo`) и в `PATCH …/accounts/{account}`
  (`AccountPatch`; `aliases` заменяет список целиком, `[]` — снять). Псевдоним приводится к нижнему регистру, повторы и
  основной адрес отбрасываются. Не адрес — 400; домен не принят организацией — 409; адрес занят другой учётной записью
  (основной адрес или псевдоним), группой рассылки или почтовым контактом — 409 с пояснением, кто его занимает. Без
  настроек транспорта домен не проверить — 503.
- Учётная запись каталога (`external_id` задан): `aliases` и `hidden_from_gal` ведёт каталог, синхронизация их
  перезаписывает — изменение через API 409 с пояснением (один источник данных).
- Создание локальной учётной записи — та же проверка занятости адреса (адрес-псевдоним новой записи не отдаётся).
- Схема `openapi_spec()` и копия консоли `console/src/api/openapi.json`, `schema.d.ts` — в том же PR (CI-11).
- CLI: `thepost admin account set <учётная запись> [--alias АДРЕС]… [--no-aliases] [--hidden-from-gal true|false]`;
  вывод `account get` — псевдонимы и признак скрытия.
- Консоль (карточка учётной записи, UI-15): у локальной записи — поля «Псевдонимы» и «Скрыть из книги «Организация»»
  в форме (`PATCH` только изменённых полей); у записи каталога полей нет, значения — в сведениях карточки.

## Приёмка
- Тесты роутера (`patch_aliases_and_gal`): псевдонимы и скрытие сохраняются; адрес занят учётной записью, группой,
  контактом, чужой домен и запись каталога — 409; не адрес — 400; без транспорта — 503.
- e2e `gal_without_ldap` (PostgreSQL): псевдоним, заданный через API, принимает почту (SMTP → IMAP) и виден в
  `calendar-user-address-set` CalDAV; адрес группы — 409; запись каталога — 409; скрытая учётная запись пропадает из
  книги «Организация» за `gal_interval`.
- CLI против Admin API (`account_set_against_admin_api`); vitest карточки учётной записи.

## Вне карточки
- Создание и изменение группы рассылки и почтового контакта пока проверяет занятость адреса только среди своих
  (групп, контактов) — не среди псевдонимов учётных записей.
