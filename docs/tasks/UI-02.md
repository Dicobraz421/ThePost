## Сделать
- `authProvider`: токен администратора (META-43) и OIDC с PKCE, если в `/api/v1/session` указан поставщик; выход, истечение токена.
- `dataProvider` поверх Admin API: `/api/v1/orgs/{org}/…`, курсоры `after`/`limit`, ошибки API — в уведомления; выбор организации.
- Типы — `openapi-typescript` из `/api/openapi.json` (файл в `console/src/api`); проверка в CI: типы совпадают со схемой узла.
- Тест покрытия: каждая операция OpenAPI — экран консоли или строка в `console/coverage-pending.txt`; новая операция без экрана
  и без строки — тест падает (критерий Ф2: список пуст).
