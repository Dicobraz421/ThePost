Хвост волны app-25, PR #442.

Требует подтверждения владельца: проверять скрипты во всех каналах с пределами секции `sieve` (рекомендация агента), а не везде с пределами по умолчанию? (PR #442, решение 2)

## Сделать
- Проверка текста в `SieveScript/validate` и `/set` — с теми же пределами (размер, вложенность и др.), с которыми скрипт
  выполняется при доставке (`tp_sieve::compile` с секцией `sieve`), а не с пределами по умолчанию: проверку с уже
  заданными пределами передаёт узел (APP-38). Admin API (PR #442) так уже делает.
- Capability `urn:ietf:params:jmap:sieve` объявляет те же пределы.

## Приёмка
- Тест: при уменьшенном пределе секции скрипт, превышающий его, отклоняется `invalidSieve` и в `/validate`, и в `/set`.
