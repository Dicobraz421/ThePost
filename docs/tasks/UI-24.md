## Сделать
- Раздел меню «Признаки риска»: переключатель уровня (установка — администратору установки, организация). Вкладка
  «Каталог» — таблица antd: `id`, происхождение (поставщик, администратор), детектор, вес, порог, действие, режим,
  источник значения; правка в строке — для организации не мягче уровня установки, ошибка 422 — у поля с `detail`
  сервера; «только отчёт» — метка с датой перехода; «осиротевшие» изменения — отдельным списком с кнопкой сброса.
  Свои признаки `org.*` — создание формой.
- Вкладка «Пороги» — четыре числа с подписями действий и пояснением «действует самое строгое».
- Вкладка «Пакеты» (администратор установки): активный, прошлые, отклонённые; загрузка файла (закрытый контур),
  отчёт проверки (подпись, lint, пробный прогон, что изменится) до активации; «Активировать», «Откатить» — с
  подтверждением.
- Вкладка «Источники TI»: список с уровнем (поставка, ключ заказчика, импорт), лицензией и атрибуцией, свежестью
  (устарел — предупреждение), числом записей; добавление — форма по виду и формату, ключ — выбор `SecretRef`, не
  значение; импорт файла, «Обновить сейчас»; учёт по организациям для MSSP.
- Вкладка «Срабатывания» — фильтры по признаку, режиму, времени; ссылка на запись журнала доставки.

## Как делают другие
- Rspamd web UI — символы и баллы, карты, история (https://docs.rspamd.com/webui/); Stalwart — настройки
  спам-фильтра и правил в веб-админке (https://stalw.art/docs/spamfilter/settings/).
- Отличие: отчёт проверки пакета виден до активации; лицензия и атрибуция каждого фида — на экране источников.

## Приёмка
- Тесты: организация не может выбрать вес ниже установки; 422 — у поля; загрузка пакета показывает отчёт и сама его
  не активирует; ключ источника — только выбор `SecretRef`; устаревший источник помечен.
- Ручная проверка на стенде: изменение веса, импорт списка, загрузка и откат пакета видны в журнале аудита.
