Находка CMP-01, п. 5а: учётная запись, заведённая напрямую в базе, без папок — `Mailbox/get` пуст. Сейчас `SYSTEM_FOLDERS`
без Archive и создаются только когда папок нет совсем.

## Сделать
- Системные папки RFC 6154: Inbox, Drafts, Sent, Junk, Trash, Archive — при создании учётной записи любым путём
  (Admin API, вход через OIDC/LDAP с созданием записи, импорт).
- Ящик без части системных папок (старые записи, заведённые в базе) дополняется недостающими при первом входе: при
  обновлении записи на входе (`upsert`) и при первом открытии ящика (`MailboxStore`, если вход идёт без `upsert`).
  Существующие папки с той же ролью или именем не дублировать.
- Тесты при `TEST_DATABASE_URL`: новая запись — 6 папок; запись без папок — дополняется; запись с Inbox — добавлены остальные.

Вопрос о заведении первой учётной записи без OIDC (п. 5б) — issue с меткой `решение`, здесь не делать.
