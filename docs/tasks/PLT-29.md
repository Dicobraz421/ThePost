Хвост реестра облачных волн, п. 40: app-32, PR #481 — ACME пишет ключ в `key_file`, узел при `tls.key` читает его из
секрета, после продления пара расходится. Решение 100 (аудит 12.11, п. 8) заменяет запрет ACME при `tls.key`
(решение 80): ключ TLS — только из OpenBao, ACME кладёт выпущенный ключ туда.

## Сделать
- `acme.rs`: после выпуска и продления — запись ключа в секрет `tls.key` (новая версия) через хранилище секретов узла,
  затем сертификат; при ошибке записи — прежняя пара остаётся, `ERROR` в журнал. Права узла — запись только своего
  пути ключа TLS (политика — DEP-44).

## Приёмка
- Тест на хранилище в памяти: продление создаёт новую версию секрета, слушатель подхватывает пару без перезапуска.
