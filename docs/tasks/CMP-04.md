Находка CMP-01, п. 4: письмо из JMAP (`EmailSubmission/set`) и submission локальному адресату уходит во внешнюю очередь и
к MX; на стенде без DNS — `TLSA lookup failed`, письмо остаётся `pending`.

## Сделать
- Получатель из `smtp.delivery.local_domains` (и каталога: домены, псевдонимы, группы) при отправке через submission и из
  JMAP доставляется локально тем же путём, что входящий SMTP (`deliver`), минуя smtp-out, MX, MTA-STS и DANE.
- Смешанный список получателей: локальные — сразу, внешние — в очередь; статус доставки по каждому получателю.
- Ошибка локальной доставки (квота, нет ящика) — DSN отправителю, как для входящего.
- Тесты: локальный получатель доставлен без обращения к DNS; смешанный список; неизвестный локальный адрес.
