## Сделать
- Экран входа — `public_branding(domain)` из `tp-admin-client`: сначала без домена, затем по домену введённого имени
  входа; после входа — `effective` своей организации (администратор установки — уровень установки). `null`, ошибка
  или нет сети — тема IT TASK TUI-06.
- Цвета ролей сервера (`sel`, `selFg`, `frameA`, `fkBg`, `fkFg`) заменяют роли темы TUI-06 только в truecolor
  (`light` или `dark` — по режиму) и в 256 цветах (ближайший цвет xterm-256 к роли тёмной темы); в 16 цветах и
  монохроме — встроенные роли, палитра консоли Linux — как в TUI-06. Строка меню — градиент от акцента к основному.
- Название продукта — вместо IT TASK в строке меню и на экране входа (длинное — с многоточием по ширине 80×24).
  Знак — `branding_logo(hash)`, PNG через `image` (`image.workspace = true` в `crates/tp-tui/Cargo.toml`; зависимость
  рабочего пространства — ADM-48) и `ratatui-image`, когда терминал умеет картинки; иначе — только название (полублоки
  куба IT TASK — только для встроенного брендинга).

## Приёмка
- Тесты на `TestBackend`: роли сервера применяются в truecolor и 256, в 16 цветах и монохроме — встроенные; название
  длиннее ширины обрезается; без графики — название без знака; `null` — тема IT TASK.
- Ручная проверка: Windows Terminal (картинка) и консоль Linux (16 цветов, только название) на стенде.
