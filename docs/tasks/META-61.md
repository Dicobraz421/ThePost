Хвост волн meta-13/14/25 (PR #393, #401, #403): на шарде, отличном от основного, срок корзины читается из каталога без
папки (`tp_trash_retention_us($1, $2, NULL)`, `retention.rs`) — политика уровня папки не действует.

## Сделать
- `trash_retention`: на другом шарде срок — по цепочке «папка → учётная запись → домен → организация» из основной БД
  для каждой исходной папки (при каскадном удалении — свой срок у писем каждой папки).

## Приёмка
- Тест PostgreSQL на двух шардах: срок, заданный на папке, действует у ящика второго шарда так же, как на основном.
