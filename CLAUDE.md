# The Post — правила для Claude Code
<!-- ≤3 КБ. Только стабильные правила. Текущая работа — в карточках docs/tasks/. -->

Open-source корпоративный почтовый сервер (замена Exchange): Rust, Linux, один бинарный файл `thepost`,
роли по config.yaml; PostgreSQL (метаданные) + BLOB (локальный диск / S3). Процесс — скилл `pets-dev`.

## Где правда
1. `docs/decisions/` — решения владельца (приоритетнее всего).
2. `docs/spec/` — SRS ред. 4 (`S3.md#3.4` = заголовок `## 3.4.`). Читать только разделы из `read:`.
3. `docs/CONTRACTS.md` и крейт `tp-contracts` — межкрейтовые контракты (менять только PR класса B).
4. Карточка `docs/tasks/<ID>.md`. План волн — `docs/PLAN.md`. Запуск, тесты, стенд — `docs/DEV.md`.

## Правила
- Полосы — `lanes.toml`; одна волна = одна полоса = один PR (`w/<полоса>-<NN>`); коммит `<ID>: суть`;
  `gh pr merge --auto --rebase`. Межполосное — только PR класса B, ветка `x/<суть>`.
- Проверки в конце волны: `cargo fmt --all`, `cargo clippy -p <крейты> --all-targets -- -D warnings`,
  `cargo nextest run -p <крейты>`; тесты с PostgreSQL — при `TEST_DATABASE_URL`, иначе пропуск.
- Крейт зависит только от `tp-contracts`, `tp-testkit` (dev) и явно разрешённых в карточке крейтов других полос.
  Тесты полосы — на in-memory реализациях `tp-testkit`.
- Запрещено: обращения к BLOB/сети внутри открытой транзакции БД; `unsafe` вне `tp-sys`; `unwrap()` вне тестов;
  макросы `sqlx::query!` (только `query`/`query_as` с `FromRow`); блокирующий I/O в async без `spawn_blocking`.
- Ошибки — `tp_contracts::Error` на границах, `thiserror` внутри. Время — UTC. Логи — `tracing`, без писем, паролей, токенов.
- Все данные и запросы — в контексте организации (tenant; транзакции через `with_tenant`, RLS). Модули — только через точки
  расширения (SRS 2.5), их данные — в схеме `mod_<имя>`.
- Все пороги, таймауты, лимиты — в секции конфигурации крейта с `Default` (SRS 5.5), не константами.
- Не трогать: чужие полосы, `Cargo.toml`/`Cargo.lock` (зависимость → карточка полосы deps), `.github/`, `docs/spec/`.
- Состав зависимостей крейтов не менять (меняет `Cargo.lock`) → карточка полосы deps.
